# 菜狗独立网页

所有题库和校园指南均通过各自的 HTML 地址独立访问。

## 后续维护约定

- 不创建或恢复汇总首页（index.html）。
- 不添加返回首页、跨题库或跨指南的导航、推荐入口和跳转按钮。
- 菜狗品牌只作展示，不链接到其他页面。
- 保留当前页面内部导航、回到顶部及官方资料链接。
- 更新时保持各独立网页的 URL、学习内容和交互功能稳定。

## 考点分析

- 全部题库使用 `assets/caigou-topic-analysis.js` 与配套 CSS，横向条形图展示主考点占比。
- `assets/caigou-topic-groups.js` 维护每套题的主分类和原题号；每题只能计入一个主分类，细考点沿用题目解析。
- 仅在每题均有有效 `score` 时提供分值统计；否则按题数展示，不推测分值。
- 点击考点显示对应题号，专项练习仅在选定题目间翻页，退出后恢复整套题；共用原有作答与进度记录。
